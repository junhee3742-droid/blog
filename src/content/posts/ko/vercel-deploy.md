블로그 코드는 다 만들었는데, 이걸 어떻게 인터넷에 올리지?

저도 여기서 막막했어요. [코딩 경험이 어느 정도인지 한 줄. 예: "저는 개발자가 아니라 신경과학 대학원생이라, 서버나 배포라는 말부터 낯설었어요."]

결론부터 말하면, **Vercel**이라는 서비스를 쓰니까 GitHub 계정으로 가입하고 버튼 몇 번 누르는 걸로 끝났어요. 실제로 걸린 시간은 [ ]분 정도였어요.

## Vercel이 뭐예요?

웹사이트를 인터넷에 올려 주는 서비스예요. 가장 편한 점은 **GitHub 저장소와 연결해 두면, 코드가 바뀔 때마다 알아서 사이트를 다시 만들어 준다**는 거예요. 한 번 연결해 두면 그다음부터는 신경 쓸 게 거의 없어요.

개인 프로젝트용 Hobby 플랜은 무료예요. (단, 광고를 붙일 계획이라면 아래 "주의할 점"을 꼭 읽어 주세요.)

## 준비물

- GitHub 계정
- 사이트 코드가 올라가 있는 GitHub 저장소

저는 Astro로 만든 블로그 코드를 `blog`라는 저장소에 올려 둔 상태였어요. 블로그 코드를 만든 과정은 [이전 글 링크]에 정리해 뒀어요.

## 따라 하기

### 1. GitHub 계정으로 가입하기

vercel.com에 들어가서 **Continue with GitHub**를 눌러요. GitHub 계정으로 바로 가입돼서 따로 아이디를 만들 필요가 없어요.

📷 [Vercel 가입 화면]

### 2. 새 프로젝트 만들기

대시보드에서 **Add New → Project**를 눌러요.

### 3. 저장소 가져오기

내 GitHub 저장소 목록이 나와요. 블로그 저장소(저는 `blog`) 옆의 **Import**를 눌러요.

📷 [저장소 목록과 Import 버튼]

### 4. 설정은 그대로 두고 Deploy

설정 화면이 나오는데, **아무것도 바꾸지 않아도 돼요.** Vercel이 Astro로 만든 사이트라는 걸 자동으로 알아채요. 바로 **Deploy**를 눌러요.

📷 [Framework가 Astro로 잡혀 있는 설정 화면]

### 5. 완료!

1~2분 정도 기다리면 배포가 끝나고, 사이트 주소가 생겨요. 저는 `blog-ten-sepia-41.vercel.app`이라는 주소를 받았어요. (지금은 아래 "주의할 점" 때문에 다른 곳으로 옮겨서 이 주소는 쓰지 않아요.)

## 이제 글은 어떻게 올려요?

여기서부터가 Vercel의 진짜 장점이에요.

배포를 한 뒤에 블로그 이름을 바꿔서 GitHub에 다시 올렸는데, **제가 아무것도 안 했는데도 1~3분 뒤에 사이트에 반영돼 있었어요.** Vercel이 GitHub를 지켜보고 있다가, 바뀐 게 생기면 자동으로 사이트를 다시 만들어 주는 거예요.

그러니까 앞으로 글을 올리는 방법은 이게 전부예요.

> **글 파일을 GitHub에 올린다. 끝.**

📷 [Vercel 대시보드의 Deployments 탭 — 배포 기록이 쌓인 모습]

## 빌드 오류가 나면?

저는 운 좋게 첫 배포에 한 번에 성공했지만, 오류가 나는 경우도 많아요. 그럴 땐 이렇게 하면 돼요.

1. Vercel 프로젝트의 **Deployments** 탭에 들어가요.
2. 빨간색(실패)으로 표시된 배포를 눌러요.
3. **Build Logs**에서 빨간 에러 메시지를 찾아요.
4. 그 메시지를 그대로 복사해서 AI에게 보여 주면, 대부분 무엇이 문제인지 바로 알려 줘요.

## 비용과 주의할 점

**무료 플랜(Hobby)으로 개인 블로그는 충분해요.** 한 달에 데이터 전송 100GB까지 포함돼 있어서, 글 위주의 블로그라면 넘길 일이 거의 없어요.

**⚠️ 그런데 광고를 붙이려면 얘기가 달라져요.**

Vercel의 무료 플랜은 **비상업적인 개인 용도로만** 쓸 수 있어요. 그리고 Vercel 공식 문서에는 상업적 이용의 예시로 "**구글 애드센스 같은 광고를 넣는 것**"이 명시돼 있어요. 즉 애드센스를 붙이는 순간 유료 Pro 플랜(사용자당 월 20달러)이 필요해요. (후원 요청은 상업적 이용에 해당하지 않는대요.)

저도 이 블로그로 나중에 수익을 내고 싶어서, 이걸 알고 나서 **글을 올리기 전에 블로그를 Cloudflare로 옮겼어요.** Cloudflare는 무료 플랜에서도 상업적 이용이 가능하고, 옮기는 데 코드는 하나도 안 바꿨어요. 옮긴 과정은 다음 글에서 자세히 쓸게요.

블로그로 수익을 생각하고 계신다면, 처음부터 이 부분을 알고 시작하시는 걸 추천해요.

## 정리

- Vercel은 GitHub 저장소만 연결하면 사이트를 인터넷에 올려 준다
- 가입 → Add New → Import → Deploy, 설정은 건드릴 필요 없음
- 그다음부터는 GitHub에 올리기만 하면 자동으로 반영
- 무료 플랜은 개인·비상업용, **광고를 붙이려면 유료 플랜이 필요**

다음 글에서는 광고 때문에 Vercel에서 Cloudflare로 블로그를 옮긴 이야기를 써 볼게요.
