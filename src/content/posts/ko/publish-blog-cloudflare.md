지난 편에서 Claude가 블로그 설계도(코드)를 다 그려서 GitHub 창고에 넣어 줬어요. 그런데 이 블로그를 볼 수 있는 사람은 아직 아무도 없었어요.

> "설계도는 있는데, 집은 어디 있어?"

![고민](/stickers/thinking.svg)

설계도를 실제 집으로 지어서 누구나 찾아올 수 있게 하는 일, 그게 오늘의 주제인 **배포**예요!

## 배포가 뭐예요?

**배포**는 내 컴퓨터나 창고에만 있던 코드를 **인터넷에 올려서 누구나 볼 수 있게 만드는 것**이에요.

1편의 집 짓기로 다시 정리해 볼게요.

| 단계 | 집 짓기로 치면 | 이 블로그에서는 |
| --- | --- | --- |
| 코드 | 설계도 | Claude가 만든 Astro 코드 |
| GitHub | 설계도 보관 창고 | `blog` 저장소 |
| **호스팅** | **땅과 건물** | **Cloudflare** |
| 배포 | 땅 위에 실제로 집을 짓기 | 창고의 코드로 블로그를 만들어 인터넷에 띄우기 |

호스팅 회사가 창고에서 설계도를 가져가 집을 지어 주고, 24시간 문을 열어 둬요. 그래서 저는 **창고와 땅을 연결만** 하면 돼요.

## 처음엔 Vercel에 지었어요

처음 고른 땅은 **Vercel**(버셀)이라는 서비스였어요. GitHub 계정으로 가입하고, 저장소를 고르고, Deploy 버튼을 누르니 1~2분 만에 블로그 주소가 생겼어요. 정말 버튼 몇 번이었어요.

그런데 첫 글을 쓰다가 Claude가 중요한 걸 찾아냈어요.

![주의](/stickers/caution.svg)

> Vercel 무료 플랜은 **비상업적인 개인 용도로만** 쓸 수 있고, 공식 문서에 **"구글 애드센스 같은 광고를 넣는 것"**이 상업적 이용의 예시로 나와 있어요.

저는 이 블로그에 나중에 광고를 붙이고 싶었어요. 그러려면 유료 플랜(월 20달러)을 쓰거나, 광고를 허용하는 다른 곳으로 옮겨야 했어요. ([Vercel 공식 문서](https://vercel.com/docs/limits/fair-use-guidelines))

## 그래서 Cloudflare로 이사했어요

"옮기는 게 힘들까?"라고 물었더니 Claude의 답은 이랬어요.

- **코드는 하나도 안 바꿔도 돼요.** 이 블로그는 완성된 페이지 파일만 만들어 내는 단순한 구조라 어느 호스팅에서든 그대로 돌아가요.
- **지금 옮기는 게 가장 좋아요.** 아직 글도 방문자도 없어서 잃을 게 없어요. 나중에 옮기면 쌓인 검색 노출이 흔들릴 수 있어요.

Cloudflare(클라우드플레어)는 무료 플랜에서도 광고를 붙일 수 있어서, 그날 바로 이사했어요.

## 따라 하기: Cloudflare에 블로그 올리기

준비물은 지난 편에서 만든 **GitHub 저장소** 하나예요.

1. **가입하기:** dash.cloudflare.com에서 무료로 가입해요.
2. **새로 만들기:** 왼쪽 메뉴의 **Workers & Pages**(또는 **Compute (Workers)**)에서 새 프로젝트 만들기를 눌러요.
3. **GitHub 연결:** GitHub 계정을 연결하고, 블로그 저장소(저는 `blog`)를 골라요.
4. **배포:** 프로젝트 이름을 정하고 배포를 눌러요. 저는 `vibelabnotes`로 했어요.
5. **완성!** 몇 분 기다리면 `vibelabnotes.내아이디.workers.dev` 같은 주소가 생겨요.

화면 이름이 조금씩 바뀌기도 해서, 막히면 그 화면을 캡처해서 AI에게 보여 주세요. "여기서 뭘 눌러야 해?"라고만 물어도 알려 줘요. 저도 그렇게 했어요.

새 주소가 잘 열리는 걸 확인한 뒤에 **Vercel 쪽 사이트는 지웠어요.** 같은 블로그가 두 주소에 있으면 검색엔진이 중복으로 볼 수 있거든요.

![축하](/stickers/celebrate.svg)

## 이제 글은 어떻게 올려요?

여기서부터가 진짜 편한 부분이에요. Cloudflare가 GitHub 창고를 지켜보고 있다가, **설계도가 바뀌면 알아서 집을 다시 지어 줘요.**

- 새 글을 GitHub에 올리면 → **3~5분 뒤** 블로그에 저절로 나타나요.
- 저는 버튼 하나 누르지 않아도 돼요.

처음 이걸 확인했을 때, 블로그가 정말 "살아 있는" 느낌이었어요.

## 비용은?

- Cloudflare 호스팅: **무료**
- 그 뒤에 `vibelabnotes.com` 주소(도메인)를 샀는데, 1년에 약 10달러였어요. 애드센스는 내가 가진 도메인만 등록할 수 있어서 필요했어요. 이 이야기는 다른 편에서 따로 쓸게요.

## 정리

- **배포** = 창고(GitHub)의 설계도로 실제 집을 지어 인터넷에 여는 것
- Vercel은 쉽지만 무료 플랜에서는 **광고 금지**
- Cloudflare는 무료에 광고도 가능, 옮길 때 코드는 그대로
- 한 번 연결하면 GitHub에 올리기만 해도 **자동으로 반영**
