티스토리에는 "예약 발행" 버튼이 있어요. 글을 미리 써 두고 원하는 시간에 올라가게 하는 기능이죠. 직접 만든 블로그에는 당연히 없었어요.

> "혹시 글 올리는 예약 기능 만들 수 있어?"

![고민](/stickers/thinking.svg)

Claude에게 이렇게 물었고, 그날 바로 생겼어요. 그런데 생각보다 재미있는 원리가 숨어 있었어요.

## 왜 저절로 안 될까?

이 블로그는 **정적 사이트**예요. 1편의 비유로 말하면, 설계도대로 집을 **한 번 지어 두면** 그대로 서 있는 집이에요. 누가 다시 짓기 전까지는 아무것도 바뀌지 않아요.

그래서 "10월 30일에 이 글을 보여 줘"라고 적어 둬도, 10월 30일에 누군가 집을 **다시 지어야** 글이 나타나요.

## 그래서 두 가지를 만들었어요

**1. 날짜가 지난 글만 보여 주기**

집을 지을 때 글의 날짜를 확인해서, **날짜가 아직 안 된 글은 빼고** 지어요. 관리자 화면에서 날짜를 미래로 정하면 그게 곧 예약이에요.

**2. 매시간 집 다시 짓기**

**GitHub Actions**라는 GitHub의 자동 일꾼에게 "매시간 Cloudflare에 다시 지어 달라고 말해 줘"라고 맡겼어요. Cloudflare에는 **배포 훅**(Deploy Hook)이라는 초인종 같은 주소가 있어서, 그 주소를 누르면 블로그를 다시 지어요.

![아이디어](/stickers/idea.svg)

두 개를 합치면 이렇게 돼요.

1. 글 날짜를 내일 오전 9시로 정하고 저장해요.
2. 오늘은 매시간 다시 지어도, 날짜가 안 돼서 빠져요.
3. 내일 오전 9시가 지나고 다음 번 다시 짓기 때 글이 들어가요.

그래서 정해 둔 시각보다 **최대 1시간 정도 늦게** 올라갈 수 있어요. 블로그 글에는 충분해요.

## 제가 직접 한 것

코드는 Claude가 다 썼고, 저는 **비밀 열쇠 두 군데 연결**만 했어요.

1. **Cloudflare에서 배포 훅 만들기:** Workers & Pages → 블로그 → Settings → Build → Deploy Hooks에서 만들고 주소를 복사해요.
2. **GitHub에 비밀값으로 저장:** 저장소 Settings → Secrets and variables → Actions에 넣어요.

![주의](/stickers/caution.svg)

배포 훅 주소는 **아는 사람 누구나 블로그를 다시 짓게 할 수 있는 초인종**이에요. 그래서 채팅이나 코드에 붙여 넣지 않고 GitHub 비밀값에만 넣었어요. Claude도 대신 넣지 않고 저에게 맡겼어요.

마지막으로 GitHub의 Actions 탭에서 **Run workflow**를 눌러 한 번 시험해 봤어요. 초록 체크가 뜨면 성공이에요!

![축하](/stickers/celebrate.svg)

## 돈은?

이번에도 **0원**이에요. GitHub Actions는 매달 무료로 쓸 수 있는 시간이 있고, 한 번에 몇 초면 끝나는 일이라 넉넉해요.

## 정리

- 정적 블로그는 다시 지어야 바뀐다
- 날짜가 지난 글만 넣기 + 매시간 다시 짓기 = 예약 발행
- 배포 훅 주소는 비밀번호처럼 다루기

이제 글을 미리 써 두고 자도 돼요. 이 글도 예약 발행으로 올라갔을지 몰라요!
