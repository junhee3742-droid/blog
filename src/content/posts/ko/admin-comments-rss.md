1편에서 직접 만든 블로그의 단점으로 "기본 기능도 직접 만들어야 한다"고 했어요. 티스토리에는 처음부터 있는 글쓰기 화면, 댓글, 구독이 저희 블로그에는 하나도 없었어요.

> "글 하나 고치려면 코드 파일을 열어야 한다고?"

![피곤](/stickers/tired.svg)

이번 편에서는 이 세 가지를 하나씩 붙여서, **진짜 블로그**가 된 이야기를 할게요.

## 1. 글쓰기 관리자 화면

"블로그에 글 수정하는 기능을 못 만드나?"라고 물었더니, Claude가 두 가지 방법을 알려 줬어요.

- **간단한 방법:** 글마다 "수정하기" 버튼을 달고, 누르면 GitHub 편집 화면으로 가기. 대신 마크다운 기호를 직접 다뤄야 해요.
- **편리한 방법:** 블로그에 워드프레스처럼 쓰는 **관리자 화면**을 붙이기. 설정이 조금 더 필요해요.

글을 자주 쓸 거라 편리한 쪽을 골랐어요. Claude는 **Sveltia CMS**라는 무료 도구로 `블로그주소/admin/`에 관리자 화면을 만들어 줬어요.

- 굵게, 제목 같은 **서식 버튼**과 **이미지 올리기**가 있어요.
- **임시저장** 스위치를 켜 두면 저장해도 블로그에는 안 보여요. 지금 이 글도 그렇게 쓰고 있어요!
- 저장하면 3~5분 뒤 블로그에 반영돼요.

**로그인은 GitHub 토큰으로 해요.** 토큰은 "이 창고만 열 수 있는 열쇠"예요. 만들 때 두 가지를 꼭 챙기라고 Claude가 알려 줬어요.

1. 저장소는 **blog 하나만** 고르기 (다른 창고까지 여는 열쇠는 필요 없어요)
2. 만료 기간은 **1년** 정도로 정하기

![주의](/stickers/caution.svg)

참고로 토큰은 비밀번호 같은 거라, Claude는 직접 넣지 않고 제가 넣었어요.

## 2. 로그인 없는 댓글

댓글은 선택지가 몇 개 있었어요.

| 방법 | 독자 입장 | 아쉬운 점 |
| --- | --- | --- |
| giscus | GitHub 계정 필요 | 일반 독자에게는 문턱이 높아요 |
| Disqus | 로그인 또는 비회원 | 무료 버전은 댓글창에 **광고**가 붙어요 |
| **직접 만들기** | **닉네임과 내용만 쓰면 끝** | 만드는 데 시간이 더 걸려요 |

일반 독자도 편하게 쓸 수 있어야 해서 **직접 만들기**로 했어요. 이미 쓰고 있는 Cloudflare의 무료 데이터베이스에 댓글을 저장하는 방식이에요.

- **스팸 방지:** 로봇만 채우는 숨은 함정 칸이 있고, 같은 사람은 10분에 5개까지만 쓸 수 있어요.
- **테스트:** 올리기 전에 작성, 목록, 함정, 도배 제한, 삭제까지 18가지를 확인했어요.
- **관리:** 댓글 관리 화면에서 관리자 비밀번호로 지울 수 있어요.

### 제가 겪은 실수

관리자 비밀번호를 Cloudflare에 넣었는데 계속 "비밀번호가 설정되지 않았다"고 떴어요. 알고 보니 **빌드(Build) 설정** 안의 칸에 넣었던 거예요. 거기는 사이트를 **만드는 동안에만** 쓰는 값이라, 실제로 돌아가는 댓글 기능은 볼 수 없어요. 이름이 똑같아서 헷갈리기 쉬워요. 같은 Settings 화면의 **Variables and Secrets**(런타임) 칸에 다시 넣으니 바로 됐어요.

![놀람](/stickers/surprised.svg)

## 3. RSS 구독

구독은 **RSS**로 했어요. RSS는 새 글이 올라오면 구독 앱(Feedly 같은)으로 알려 주는 방식이에요. 이메일 같은 개인정보가 필요 없어요.

- 한국어 피드 `/ko/rss.xml`, 영어 피드 `/en/rss.xml`
- RSS가 낯선 분들을 위한 **구독 안내 페이지**도 만들었어요. Feedly 버튼을 누르고 Follow만 누르면 끝이에요.
- 글 끝 뉴로니 카드에 "새 노트 구독하기" 링크도 넣었어요.

## 돈은?

이번에도 **0원**이에요. 관리자 화면, 댓글, 구독 모두 무료 도구와 Cloudflare 무료 플랜으로 만들었어요.

## 다음 편 예고

이제 글도 쓰고, 댓글도 받고, 구독도 돼요. 마지막으로 남은 건 **사람들이 블로그를 찾아오게 하는 것**이에요. 다음 편에서는 내 주소(도메인)를 사고, 구글과 네이버에 블로그를 등록한 이야기를 할게요!
